# FORGE ATHLETICS — Responsive Gym Website

A premium black/red fitness website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete page structure
- `style.css` — responsive design, layout, animations
- `script.js` — mobile menu, smooth scrolling and reveal animations
- `assets/forge-athletics-full.png` — full logo
- `assets/forge-athletics-compact.png` — compact logo

## Run
Open `index.html` directly in Chrome, or use VS Code Live Server.

## Customize
Search these placeholders in `index.html`:
- `hello@forgeathletics.com`
- `+910000000000`
- Client names/testimonials
- Stats and program text

No framework is required.
